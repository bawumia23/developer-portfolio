# Tajudeen Bawumia | Developer Portfolio

A modern, responsive developer portfolio website showcasing my technical skills, projects, and journey into software engineering.

## Live Demo

Coming soon.

## Features

- Responsive, mobile-first design
- Dark and light theme toggle
- Theme preference saved with localStorage
- Mobile hamburger navigation
- Smooth scrolling navigation
- Interactive project detail modals
- Responsive skills and project grids
- Accessibility-focused navigation and controls

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser localStorage API
